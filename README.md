# thione

由dupy, renamepy, transpy三个项目集成而来, 这三个仓库后续大概率不再维护, 新功能以及安全更新优先维护本项目 

## 功能

### 图片查重

- 扫描指定文件夹, 基于感知哈希 (dHash) 查找视觉上重复的图片 

- 在分组窗口中逐组勾选需要保留的图片 可删除或整理到 `重复项` 子文件夹 

### 批量重命名

- 可同时添加多个文件夹 每个文件夹独立选择路径 筛选与预览 
- 按 前缀 + 起始序号 批量改名 
- 保存位置选原文件夹即覆盖原文件夹的内容 

### 划词翻译

- 选中任意文本后连续按两次 `Ctrl` 即可翻译 
- 托盘菜单可打开主窗口 暂停热键或退出 

### 进制转换

- 在 2 到 36 进制之间转换数字 输入即出结果 
- 结果区同时给出二进制 八进制 十进制 十六进制的换算结果 
- 支持负数与超大整数 可直接粘贴带 `0b` `0o` `0x` 前缀或者用空格分隔的数字 
- 页面下方给出 0 到 15 的四种进制对照表 

### 端口与占用

- 扫描本机端口 列出被占用的端口以及占用端口的程序 
- 按端口号查询占用情况 也可以反查某个文件被哪个程序占用 
- 展示进程的路径 命令行 启动时间与内存等详情 可直接强制结束进程 

### 文件格式转换

- 把音频 视频或加密音乐文件批量转换成 MP3 WAV FLAC M4A OGG OPUS WMA AIFF 等常见格式 
- 视频文件只提取其中的音频轨; 网易云音乐的 ncm 加密文件会先还原成 flac 或 mp3, 歌曲信息与封面一并写入输出 
- 可以一次添加多个文件 也可以整个文件夹一起加入 目录会递归查找受支持的文件 
- 音质分无损 最高音质与 128 / 192 / 256 / 320 kbps 码率 三类: WAV FLAC AIFF 只有无损 M4A 与 OGG 可选无损 (ALAC / FLAC) 有损格式另有 最高音质 (自动) 档 自动按源文件声道数取编码器的最高码率 
- 目标格式与源文件相同时直接复制文件, 不重新编码, 不会因为二次转换损失音质 

### 串口助手

- 通过本机串口或者网络 (TCP Client TCP Server UDP) 与外部设备收发数据 两条链路可以同时打开 
- 收发数据支持 文本 HEX DEC OCT BIN 五种形式 文本模式可选 UTF-8 与 GBK 编码 
- 接收区支持自动换行 保存成 txt 与接收量统计 发送区支持固定后缀 循环发送与载入文本文件 
- TCP Server 可以把数据发给全部 单个或者部分已连接的设备 TCP Client 提供测试连接按钮 
- 载入配置前会先检查本机端口能否绑定与目的地址能否连接 端口被占用时给出占用它的程序 

## 如何使用

- Python 3.10 及以上 

```bash
pip install -r requirements.txt
python main.py
```

## 打包

```bash
pyinstaller --noconfirm --clean thione.spec
```

## 数据目录

| 用途      | 路径                                      |
| ------- | --------------------------------------- |
| 翻译设置与凭据 | `%APPDATA%\thione\config.ini`           |
| 界面偏好    | `%APPDATA%\thione\settings.ini`         |
| 运行日志    | `%LOCALAPPDATA%\thione\logs\thione.log` |
