# 配置与数据

## 目录约定

| 用途 | 路径 |
| --- | --- |
| 划词翻译的服务选择 翻译语言与华为云凭据 | `%APPDATA%\thione\config.ini` |
| 界面偏好 | `%APPDATA%\thione\settings.ini` |
| 运行日志 | `%LOCALAPPDATA%\thione\logs\thione.log` |
| 只读资源 | 程序目录下的 `assets\` 打包后解压到临时目录 |

用户数据一律不写在程序目录 因此程序放在只读位置也能正常工作 

## 划词翻译配置

`config.ini` 分成两个段 服务选择与翻译语言放在 `[translate]` 段 凭据放在 `[huawei]` 段 两者分开存放 换服务时不必重填凭据 清空凭据也不会丢掉服务选择 

```ini
[translate]
provider = uapi
source_lang = auto
target_lang = auto

[huawei]
ak =
sk =
project_id =
region = cn-north-4
```

- `provider` 取 `huawei` (华为云 NLP) `uapi` (uapipro 免费接口) 或 `sixty` (60s API 在线翻译) 未知值回落到 `huawei` 没有这一段时同样按 `huawei` 处理 
- `source_lang` 与 `target_lang` 使用本项目的领域语言代码 例如中文是 `zh` 繁体中文是 `zh-Hant` 源语言的 `auto` 表示交给服务端识别 目标语言的 `auto` 表示 中文译为英文 其它语言译为中文 源语言与目标语言都选中文时按译成英文处理 没有这两项时按 `auto` 与 `auto` 处理 
- 翻译语言可以在界面里选择 默认源语言自动识别 目标语言自动 各服务支持的语言不完全相同 换服务时不受支持的选择会自动回落到默认值 
- 选 `uapi` 或 `sixty` 时不需要凭据 缺少 AK / SK / PROJECT_ID 不算错误 
- 选 `huawei` 时三项必须齐全 否则页面显示未配置 点启动翻译也不会挂上热键 
- 华为云单次最多 2000 字符 uapipro 免费接口单次最多 3000 字符 超出时界面直接提示 不发起请求 60s API 未公布单次上限 由服务端自己校验 
- 服务选择与语言选择只从配置文件读取 环境变量与 `.env` 仍然只提供华为云凭据 

## 凭据来源优先级

由高到低 

1. 环境变量 `HUAWEI_AK` `HUAWEI_SK` `HUAWEI_PROJECT_ID` `HUAWEI_REGION` 
2. `%APPDATA%\thione\config.ini` 界面保存的主落点 
3. `%APPDATA%\thpy\config.ini` 更名前留下的旧配置 
4. `%APPDATA%\transpy\config.ini` 独立版 transpy 留下的旧配置 
5. 程序所在目录的 `.env` 
6. 当前工作目录的 `.env` 
7. 程序所在目录的 `IAM_transpy-accessKeys.csv` 只提供 AK/SK 

每一项单独取值 因此可以混用 例如 AK/SK 来自旧配置 而 region 来自环境变量 

这些来源只服务于华为云 NLP 选 uapipro 免费接口或 60s API 在线翻译时不需要任何凭据 

### 从更名前或独立版迁移

不需要做任何事 程序会自动读取更名前留下的 `%APPDATA%\thpy\config.ini` 与独立版留下的 `%APPDATA%\transpy\config.ini` 用户在新界面点一次 `保存凭据` 或 `启动翻译` 之后凭据就写到新位置 旧文件可以保留也可以删除 

`.env` 与 `IAM_transpy-accessKeys.csv` 属于便携版用法 把它们放在程序目录 (源码运行即项目根目录) 同样会被读取 

## 界面偏好

界面偏好保存在 `%APPDATA%\thione\settings.ini` 的 `[ui]` 段 记录当前主题与最近使用的页面

```ini
[ui]
theme = light
page = dedupe
```

`theme` 支持 `light` 与 `dark` 无效或缺失时使用浅色主题 历史页面偏好仍然有效
## 凭据安全

- AK/SK 只在本地读写 不写入代码 不随程序分发 
- 文件权限沿用系统对 `%APPDATA%` 的保护 同一用户下的其它程序可以读取 这是 Windows 用户级配置的固有边界 
- `.gitignore` 已排除 `.env` 与 `IAM_*-accessKeys.csv` 避免误提交 
- 界面上 SK 以密文显示 测试连接与保存都需要显式点击 
- 走 uapipro 免费接口或 60s API 在线翻译时不会发送任何凭据 只把待翻译的文本与语言选择发给对应服务
