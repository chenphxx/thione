# 批量重命名

## 功能目标

按 前缀 + 起始序号 的方式批量重命名文件 可以原地改名 也可以统一保存到另一个文件夹 

## 实现原理

### 文件收集

- 页面上可以放多张文件夹卡片 每张卡片独立保存路径 扩展名筛选与勾选结果 
- 页面把所有卡片里勾选的文件拼成一个列表 新名字 = 前缀 + 序号 + 原扩展名 序号从起始数字开始按列表顺序递增 
- 卡片内部的文件视图与预览窗格与图片查重共用同一套组件 见 `docs/架构.md` 的 资源管理器风格的浏览组件 

### 执行

- 任务先按目标位置分成两类: 目标文件夹与原文件夹相同的算原地改名 其余算复制到目标位置并按新名字保存 
- 原地改名最容易出的问题是新旧名字互相占用 例如 a 改成 b 的同时 b 要改成 c 因此先将与其它任务目标同名的文件挪到临时名字 全部改完再统一改名 中途失败按记录回滚 
- 目标位置已有同名文件时由页面询问 覆盖 或者 跳过 也可以把这次的选择应用到全部冲突 
- 执行放在后台线程 进度 冲突与终止判断都通过回调交给主线程 后台线程不碰 tkinter 对象 

### 预览

- 可预览的类型包括图片 文本 CSV 与 Excel 覆盖范围与 Windows 资源管理器的预览窗格一致 
- 详细信息窗格展示名称 类型 大小 修改时间 位置 图片额外显示像素尺寸 

## 使用的依赖

| 依赖 | 用途 | 缺失时的表现 | 
| --- | --- | --- | 
| Pillow | 生成缩略图与图片预览 | 必需 程序依赖它启动 | 
| openpyxl | 读取 Excel 工作表用于预览 | 可缺失 缺少时 Excel 预览降级为提示 其它功能不受影响 |
