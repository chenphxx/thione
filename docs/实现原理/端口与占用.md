# 端口与占用

## 功能目标

查看本机端口被哪些程序占用 反过来也可以查询某个文件被哪个程序占用 并可以直接结束占用进程 

## 实现原理

### 连接枚举

- 连接表取自 IP 助手 API 的 `GetExtendedTcpTable` 与 `GetExtendedUdpTable` 这两支接口直接返回带拥有者 PID 的连接表 
- 不解析 `netstat` 的文本输出 因此不受系统显示语言影响 也不需要管理员权限 
- IPv4 与 IPv6 各有一张表 界面按协议与本地端口展示 默认只看监听中的连接 

### 进程信息

- 进程名与父进程通过 Toolhelp32 快照 (`CreateToolhelp32Snapshot` `Process32FirstW` `Process32NextW`) 获取 
- 可执行文件路径用 `QueryFullProcessImageNameW` 启动时间用 `GetProcessTimes` 内存用 `GetProcessMemoryInfo` 
- 命令行只在本程序是 64 位且目标不是 WOW64 进程时才从进程环境块读取 (`NtQueryInformationProcess` 配合 `ReadProcessMemory`) 读不到的项显示 `-` 
- 以上全部通过 ctypes 调用系统 DLL 不引入第三方库 

### 文件占用

- 占用者通过 Windows 重启管理器 (`RmStartSession` `RmRegisterResources` `RmGetList`) 查询 系统弹出 该文件正被另一个程序使用 时依据的就是这套接口 
- 重启管理器不返回占用者时 再用不共享的方式 `CreateFileW` 打开一次文件做复核 能打开说明文件确实空闲 打不开说明占用者不在重启管理器的可见范围内 
- 读完就释放句柄的程序 (多数图片查看器) 不会被列出来 这是重启管理器的行为 不是漏报 

### 结束进程

- 结束走 `TerminateProcess` 与任务管理器的 结束任务 等价 需要对该进程有 `PROCESS_TERMINATE` 权限 
- 结束以管理员身份运行的进程需要 thione 自身也以管理员身份启动 权限不足时按系统错误码给出提示 
- 结束前会先让用户确认 结束后等目标真正退出再刷新列表 因此占用记录不会残留 

## 使用的依赖

只使用 Python 标准库 (ctypes) 与 Windows 自带的系统 DLL 没有第三方依赖
