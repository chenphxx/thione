# 图片查重

## 功能目标

在指定文件夹里找出视觉上重复的图片 按组展示 并支持逐组清理或者整理 

## 实现原理

### 扫描与浏览

- 递归遍历所选文件夹 按扩展名筛出可解码的图片 扫描结果同时作为文件视图的数据源 
- 文件视图只读取当前视口内的文件 缩略图在后台线程解码 结果经队列分批贴回画布 因此打开大文件夹时不会一次性读进几千张图 
- 已解码的缩略图按最近使用顺序缓存 超出上限后淘汰 换档位或换展示方式时直接用缓存重画 不回磁盘 

### 视觉相似度

- 用差值哈希 (dHash) 描述一张图片: 先转成灰度图 缩放到 9x8 像素 再逐行比较相邻像素的明暗 得到一个 64 位整数 
- 两张图片的差异用汉明距离衡量 即两个哈希值异或后 1 的个数 距离不超过阈值的算作重复 
- 阈值可以在 `app/tools/dedupe/constants.py` 的 `HASH_THRESHOLD` 调整 调大更容易判为重复 调小更严格 
- 分组办法是两两比较: 依次取还没有归组的图片作为一组 与它后面的图片逐一比对 距离在阈值内的并入同一组 
- 哈希计算只用 Python 的整数运算 不依赖数值计算库 因此不需要 NumPy 之类的依赖 

### 整理

- 结果按组展示 默认保留每组的第一张 其余图片由用户勾选 
- 勾选后的处理方式有删除 以及移动到同目录下的 `重复项` 子文件夹 移动前会先建目录 
- 删除与移动都是普通的文件操作 失败时按系统错误码提示原因
