# 进制转换

## 功能目标

在 2 到 36 进制之间转换整数 输入即出结果 并附带常用进制的对照表 

## 实现原理

### 解析

- 输入先按 NFKC 归一化 全角数字与全角符号变成半角 空格 逗号 下划线作为分隔符直接忽略 因此从别处复制过来的数字可以直接粘贴 
- 允许正负号 以及与该进制匹配的 `0b` `0o` `0x` 前缀 
- 逐字符校验是否落在该进制的可用字符里 不合法时给出这个进制允许的字符范围 
- 解析交给 Python 原生的 `int(text, base)` 整数没有位数上限 超大整数也能转换 

### 输出

- 二进制 八进制 十进制 十六进制走 `format()` 的内置快速路径 其余进制用短除法逐位取余 
- 十以上的进制统一使用大写字母 A-Z
