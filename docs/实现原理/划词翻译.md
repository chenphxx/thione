# 划词翻译

## 功能目标

在任意程序里选中文本后 连续按两次 Ctrl 就能看到译文 翻译服务可以在华为云 NLP uapipro 免费接口 60s API 在线翻译 腾讯交互翻译 Google 翻译 与 有道翻译之间切换 

## 实现原理

### Provider架构

翻译相关代码分成两层: 业务层 (`page.py` `service.py` `hotkey.py`) 只认统一接口与服务元数据 各服务自己的差异全部留在 `providers/` 内

- `providers/provider.py` 定义统一接口 `TranslationProvider.translate(text, source_lang, target_lang)` 统一异常 `TranslationError` 以及注册表 `PROVIDER_SPECS`
- 注册表为每家服务记录显示名 说明文案 是否需要凭据 单次长度上限 语言代码表与构造方式 界面展示与配置校验都从这里取 业务层因此不出现 `if provider == ...` 这类判断
- `providers/huawei.py` `providers/uapi.py` `providers/sixty.py` `providers/transmart.py` `providers/google.py` `providers/youdao.py` 分别封装一家服务 各自负责接口地址 请求方式 参数转换 认证 响应解析与异常转换
- 构造方式在真正用到时才导入对应模块 没被选中的服务不会被加载 华为云 SDK 与 uapi SDK 都只在选中该服务后才进场
- 语言代码分两层: 业务层统一使用领域语言代码 (`zh` `zh-Hant` `en` 等) 各服务自己的取值 (华为云 `zh-tw` 60s API `zh-CHS` Google `zh-CN` uapipro 与 腾讯交互翻译 `zh-TW`) 由 Provider 内部转换 不支持的语言在发起请求前就转成 `TranslationError`
- 新增一家服务只需在 `providers/` 下加一个实现模块 并在 `PROVIDER_SPECS` 里补一条记录 页面 热键与配置读写都不需要改动

### 触发与取词

- 用 pynput 挂全局键盘监听 统计用户真实按下的 Ctrl 
- 两次按下之间的间隔上限见 `app/tools/translate/constants.py` 的 `DOUBLE_PRESS_INTERVAL` 超过 `CTRL_HOLD_LIMIT` 的按住算长按 不计入双击 两次之间夹了别的按键也不计 
- 命中后由程序自己合成 Ctrl+C 把选中文本复制到系统剪贴板 再读回剪贴板内容 合成出来的按键带有注入标记 会被识别并忽略 不会把自己合成的按键当成新的 Ctrl 按下 
- 监听回调运行在 pynput 自己的线程里 它只把待展示的文本投递到队列 由主线程的轮询取出并展示 线程里不创建也不操作 tkinter 对象 

### 翻译服务

- 六家服务用同一套 Provider 接口 服务之间的差异全部留在 `providers/` 内 新增一家服务只需要加一个实现模块与一条注册表记录 
- 华为云 NLP: 需要 AK / SK / Project ID 凭据 单次最多 2000 字符 源语言与目标语言都可以指定 
- uapipro 免费接口: 不需要凭据 单次最多 3000 字符 源语言由服务端识别 通过官方 SDK 调用 
- 60s API 在线翻译: 不需要凭据 直接用 HTTP 调用 源语言与目标语言都可以指定 数据来自有道翻译 公共实例有频率限制 因此不做自动重试 只把服务端的说明转成用户可读的提示 
- 腾讯交互翻译: 不需要凭据 直接用 HTTP 调用 单次最多 6000 字符 源语言与目标语言都可以指定 支持中英日韩法德西葡俄阿泰越土意等语言 
- Google 翻译: 不需要凭据 使用网页端免费端点 可选语言最多 源语言与目标语言都可以指定 长文本由服务端自行拆句 译文按段拼接 
- 有道翻译: 不需要凭据 使用 AI 体验接口 只提供中英日三种语言 翻译至少一侧为中文 单次最多 1000 字符 有访问频率限制 触发后提示稍后再试 不做自动重试 
- 语言在本项目内部统一使用领域代码 (`zh` `zh-Hant` `en` 等) 各服务自己的语言代码由 Provider 负责转换 服务不支持的语言在发起请求前就报错 

### 运行方式与托盘

- 页面上点 启动翻译 之后挂上键盘钩子 同时用 pystray 显示托盘图标 菜单可以打开主窗口 暂停热键与退出 
- 停止翻译会一并结束键盘监听线程与托盘图标 不留后台钩子 
- 运行状态同时显示在页面与外壳状态栏 页面还能看到当前使用的服务与翻译方向 

### 配置

- 服务选择 源语言 目标语言与华为云凭据保存在 `%APPDATA%\thione\config.ini` 详见 `docs/配置与数据.md` 

## 使用的依赖

| 依赖                 | 用途                                     | 缺失时的表现                      |
| ------------------ | -------------------------------------- | --------------------------- |
| pynput             | 全局键盘监听与合成 Ctrl+C                       | 必需 程序依赖它启动                  |
| pyperclip          | 读写系统剪贴板                                | 必需                          |
| pystray            | 托盘图标与菜单                                | 必需                          |
| Pillow             | 生成托盘图标                                 | 必需                          |
| huaweicloudsdkcore | 华为云的签名与请求基础设施                          | 只影响华为云一路 缺少时该服务提示安装依赖       |
| huaweicloudsdknlp  | 华为云 NLP 文本翻译接口                         | 同上                          |
| uapi-sdk-python    | uapipro 免费翻译接口 SDK                     | 只影响 uapipro 一路 缺少时该服务提示安装依赖 |
| httpx              | 60s API 在线翻译 腾讯交互翻译 Google 翻译 与 有道翻译的 HTTP 调用 也是 uapi SDK 的传输层 | 只影响使用 HTTP 调用的几路服务 |
