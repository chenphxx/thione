# 开发与打包

## 环境

- Windows 
- Python 3.14 仓库根目录的 `.venv` 就是开发与打包用的解释器 3.10 及以上同样可以运行 
- 依赖见根目录 `requirements.txt` 

```bash
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`openpyxl` 只在批量重命名的 Excel 预览里用到 缺失时该功能降级为提示 其余功能不受影响 

`uapi-sdk-python` 只在 uapipro 免费翻译里用到 缺失时该服务提示安装依赖 华为云 NLP 与 60s API 在线翻译不受影响 

`httpx` 被 uapipro 免费翻译与 60s API 在线翻译用到 它随 `uapi-sdk-python` 一起安装 已在 `requirements.txt` 里显式声明 

## 运行

```bash
.venv\Scripts\python.exe main.py
```

调试时日志同时输出到终端与 `%LOCALAPPDATA%\thione\logs\thione.log` 

## 打包

```bash
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean thione.spec
```

产物为单文件 `dist\thione.exe` 打包使用仓库内的 `thione.spec`

### spec 中的功能收集

- `assets/images/logo.ico` 用于窗口和托盘图标
- Pillow 用于图片缩略图 预览 占位图和托盘图标 AVIF 插件不参与打包 预览支持的格式见 `app/browser/constants.py`
- `openpyxl` 用于 Excel 文件预览 `uapi` 用于 uapipro 翻译 两者为延迟导入 因此在 `hiddenimports` 中显式声明
- `pystray._win32` 为托盘图标的 Windows 后端 需要显式声明
- 查重使用 Pillow 和 Python 整数计算 dHash 不再依赖 ImageHash NumPy SciPy 或 PyWavelets `numpy` 也从打包配置排除 以免被 `openpyxl` 的可选探测导入
- `version='version_info.txt'` 用于设置任务栏和文件属性中显示的版本信息
## 新增一个工具

1. 在 `app/tools/` 下新建子包 
2. 实现一个 `ToolPage` 子类 声明 `key` `title` `icon` `subtitle` 四个类属性 
3. 在 `app/tools/__init__.py` 的 `TOOL_PAGES` 里登记 顺序即侧栏顺序 

外壳会自动为它生成侧栏入口 页面容器和状态栏 工具本身只需要填自己的内容 

注意事项 

- 页面是 `ttk.Frame` 不要在构造里创建 `Tk` 根窗口 也不要调用 `mainloop` 
- 需要后台线程时 结果一律经队列交给主线程 不要在线程里碰 tkinter 对象 
- 需要在窗口关闭时收尾 (停线程 存设置) 就实现 `on_close()` 
- 页面顶部用基类的 `build_toolbar()` 与 `add_divider()` 搭骨架 标题与说明放左侧 操作按钮放右侧的 `actions` 需要第二行筛选控件时在返回的 `bar` 里再加一行 
- 卡片内部的列表用 `Card.Treeview` 样式 卡片内部的文件视图把 `FileGrid` 的 `surface` 传成 `card` 否则底色会与卡片底色不一致 
- 需要文件视图 预览窗格或详细信息窗格时 直接用 `app/browser/` 下的 `FileGrid` `PreviewPane` `DetailsPane` 与 `view_bar` 不要各写一份 
- 展示方式与缩略图档位由 `view_bar` 的 `ViewSwitch` 统一切换 列表与缩略图都用同一个 `FileGrid` 不要为列表另写一份控件 
- 页面里的文件区高度不要写死 用 `fill="both"` 加 `expand=True` 让它撑满剩余空间 内容超过可视区时由 `FileGrid` 自己的滚动条处理 
- 没有内容可显示时给出引导文案与下一步动作 参考图片查重页的空状态占位块 
- 颜色一律从 `self.theme.palette` 取 不要在页面里写死色值 常用令牌有 `bg` `panel` `card` `text` `muted` `accent` `link` `border` `danger` 状态层用 `hover` `active` `selected` `disabled` 
- 字体用 `app.theme` 的 `sans()` 与 `mono()` 不要直接写字体族 
- 画在侧栏或卡片上的 Canvas 用 `_thione_surface` 声明表面层 见 `docs/架构.md` 的 主题与视觉 
- 按钮外观由 `app/theme.py` 中的 ttk 按钮样式统一控制 新增按钮变体时优先在那里定义和映射样式 不要在页面里重复设置颜色 

## 已知约束

- 单实例 重复启动不会开出第二个窗口 第二个实例会把已有窗口唤到前台 
- 划词翻译默认不启动 需要在划词翻译页面点 `启动翻译` 启动后热键全局生效并出现托盘图标 关闭主窗口即整体退出 
- 托盘图标与热键只在翻译启动期间存在 二者分属不同后台线程 停止或退出时对托盘停止有 2 秒超时保护 避免卡住退出流程
