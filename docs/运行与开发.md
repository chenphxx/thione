# 运行与开发

## 环境

- Windows, 本机使用python解释器为`3.14.7`, 前期开发时使用`3.10.6` 
- 推荐使用venv虚拟环境, 依赖见根目录`requirements.txt` 

```bash
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 运行与打包

```bash
.venv\Scripts\python.exe main.py
```

调试时日志同时输出到终端与`%LOCALAPPDATA%\thione\logs\thione.log` 

使用下面这一行命令打包 

```bash
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean thione.spec
```

## 新增一个工具

1. 在`app/tools/`下新建子包 
2. 实现一个`ToolPage`子类, 声明`key` `title` `icon` `subtitle` 四个类属性 
3. 在`app/tools/__init__.py`的`TOOL_PAGES`里登记, 顺序即侧栏顺序 

外壳会自动为它生成侧栏入口, 页面容器和状态栏, 工具本身只需要填自己的内容 

本机使用python解释器为`3.14.7`, 前期开发时使用`3.10.6`

## 目录约定

| 用途                   | 路径                                      |
| -------------------- | --------------------------------------- |
| 划词翻译的服务选择 翻译语言与华为云凭据 | `%APPDATA%\thione\config.ini`           |
| 界面偏好                 | `%APPDATA%\thione\settings.ini`         |
| 运行日志                 | `%LOCALAPPDATA%\thione\logs\thione.log` |
| 只读资源                 | 程序目录下的 `assets\` 打包后解压到临时目录             |

## 划词翻译配置

`config.ini` 分成两个段 服务选择与翻译语言放在 `[translate]` 段 凭据放在 `[huawei]` 段 两者分开存放 换服务时不必重填凭据 清空凭据也不会丢掉服务选择

```ini
[translate]
provider = uapi
source_lang = auto
target_lang = auto

[huawei]
ak =
sk =
project_id =
region = cn-north-4
```

## 界面偏好

界面偏好保存在 `%APPDATA%\thione\settings.ini` 的 `[ui]` 段 记录当前主题与最近使用的页面

```ini
[ui]
theme = light
page = dedupe
```
