# 项目架构

## 项目结构

```text
main.py                     单实例入口与 Tk 主循环
app/
  theme.py                  浅色与深色配色及 ttk 控件样式
  kit.py                    设计稿风格的基础部件 (面板 控件框 分段控件 表格 状态栏)
  settings.py               界面偏好与工具级缓存
  imaging.py                缩略图与图片占位图
  browser/                  查重与重命名共用的文件浏览和预览组件
  shell/
    main_window.py          主窗口 页面切换与跨线程消息队列
    sidebar.py              简洁工具导航
    page.py                 工具页面基类与共用顶栏 内容区
  tools/
    dedupe/                 图片查重与重复项整理
    rename/                 批量重命名
    translate/              划词翻译与翻译 Provider
    radix/                  进制转换与常用进制对照表
    port/                   端口与文件占用查询
    convert/                音频格式转换 平台加密文件还原与 ffmpeg 定位
    comm/                   串口助手 串口与网络会话
assets/images/logo.ico      窗口与托盘图标
```

## 页面模型

每个工具继承`ToolPage`, 并由`app/tools/__init__.py`注册 

切换页面时外壳先把新页面绘制出来, 再在空闲时调用它的`on_show()`; 因此`on_show()`里不要做会阻塞的事情 (读配置 列设备 找外部程序), 需要等待时就投给后台线程, 结果再经队列回到主线程刷新界面 

## 主题与视觉

界面提供浅色与深色两套主题, `app/theme.py` 集中定义两套颜色令牌 令牌名与设计稿的
CSS 变量一一对应: `canvas` 页面底色 `side` 导航栏与状态栏底色 `panel` 面板底色
`fill` 控件底色 `fill_hi` 选中底色 `text` `muted` `hair` 1 像素描边 `accent`
`on_accent` `accent_soft` `ok` `danger` `warn` `ph1` `ph2` 缩略图占位渐变 

界面统一是方角 只用 1 像素描边与色块分层; 字号用像素值 (tkinter 里负数字号即像素)
与设计稿一致 

导航栏默认 208 像素宽, 与主列之间有一条 5 像素的拖拽分隔条, 宽度可在 180 到 320
像素之间调整; 导航栏文字比设计稿大 1 像素, 保证在常见缩放下依然清晰 

`app/kit.py` 提供设计稿里的固定零件: `Panel` 面板 (34 像素头部可选) `Field` 控件框
`EntryField` 输入框 `Area` 多行文本块 `Dropdown` 下拉框 `Segment` 分段控件
`Check` 勾选行 `RadioRow` 单选项行 `Dot` 状态圆点 `Table` 表格 `Track` 进度细条
`StatusRow` 状态栏内容 `Splitter` 拖拽分隔条 零件在构造时登记配色角色 (`_thione_roles`) 或实现
`_thione_apply(palette)` 主题切换时由 ThemeManager 统一重绘 

`Dropdown` 的弹出列表不用系统菜单, 而是自建的置顶窗口: 宽度与控件框一致 样式沿用
同一套方角与细描边, 项目较多时列表内部滚动; 占用列表与进程详情 接收区与发送区
侧栏与主列之间都用 `Splitter` 拖动调整尺寸, 拖动范围由各页面自己夹紧 

页面骨架由 `app/shell/page.py` 的 `ToolPage` 提供: 顶栏 62 像素 (左侧工具名与说明
右侧操作按钮 底部 1 像素分隔线) 与内容区 (左右各 20 像素 顶部 18 像素) 页面底部的
状态栏由外壳统一提供, 内容通过 `self.status` 填充, 切换页面时外壳负责显示与收起 

# 架构

## 线程模型

tkinter 有线程亲和性 所有窗口只能在主线程创建和销毁 因此除主线程外 其余线程一律不碰 tkinter 对象 

| 线程          | 职责                                   |
| ----------- | ------------------------------------ |
| 主线程         | 唯一的 Tk 根窗口与 `mainloop` 所有窗口 定时器 主题操作 |
| pynput 监听线程 | 键盘事件 命中双击 Ctrl 后取剪贴板并调用翻译接口          |
| pystray 线程  | 托盘图标与右键菜单                            |
| 激活监听线程      | 监听第二个实例发来的激活请求                       |

pynput 与 pystray 两个线程只在划词翻译启动期间存在 停止翻译会一并结束它们 因此程序空闲时没有键盘钩子 也没有托盘图标 

跨线程有两处投递通道 都采用 队列 + `after` 轮询 的模式 

- `ShellWindow.post(action)` 外壳级 供激活监听线程使用 轮询间隔 200 毫秒 
- `TranslateService._post(action)` 翻译服务内部 供热键与托盘回调使用 轮询间隔 60 毫秒 

两者的约定相同 投递方只入队 由主线程的轮询取出并执行 

退出时外壳会先取消自己的轮询定时器 再销毁根窗口 页面若持有定时器 也在 `on_close()` 里自行取消 

## 资源管理器风格的浏览组件

工具中文件展示方式完全一致, 都由`app/browser/`下的四个部件实现 

| 模块                | 职责                                 |
| ----------------- | ---------------------------------- |
| `file_grid.py`    | 文件视图 支持列表与缩略图两种展示方式 支持选中 双击打开与右键菜单 |
| `preview_pane.py` | 右侧预览列 276 像素宽: 预览框 属性字段与打开按钮 支持图片 文本 表格 以及未知类型的文本兜底 |
| `details_pane.py` | 底部详细信息窗格 名称 类型 大小 修改时间 与位置         |
| `view_bar.py`     | 展示方式与缩略图大小分档 以及右下角的两个窗格开关          |

缩略图方框为 148 x 98 (中档), 没有图片时用 `ph1 -> ph2` 的 140 度线性渐变占位;
列表展示时如有 `set_secondary_text` 提供的改后文件名, 行内会画出 `原名 -> 改后名`
